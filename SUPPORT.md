# Support

## Where to get help

- Use GitHub Issues for reproducible bugs and focused feature requests.
- Read the README and docs/ for installation, game rules, testing, and deployment.
- Report security concerns privately using SECURITY.md.

## Include in a bug report

- Browser and version.
- Operating system and device type.
- Steps to reproduce.
- Expected and actual behavior.
- Console errors, if relevant.
- Screenshot or short recording for visual issues.

## Do not include

Do not post personal information, credentials, private account details, or unrelated sensitive material.

## Response expectations

This is a small maintained project, not a commercial support service. Response times are not guaranteed. Clear reproduction steps and a focused description make issues easier to investigate.
