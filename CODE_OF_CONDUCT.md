# Code of Conduct

## Commitment

Participation in this project should be respectful, constructive, and focused on improving the software. People with different backgrounds and levels of experience are welcome.

## Expected behavior

- Be respectful when discussing technical disagreements.
- Give specific, actionable feedback.
- Critique code and decisions, not people.
- Respect privacy and do not publish credentials or personal information.
- Keep project discussions relevant and useful.
- Accept responsibility for mistakes and correct inaccurate information.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Deliberate intimidation or repeated unwanted contact.
- Publishing private information without permission.
- Trolling, sustained disruption, or abusive language.
- Deliberately submitting malicious code or credential theft attempts.

## Maintainer response

The maintainer may edit or remove comments, close discussions, reject contributions, or restrict participation when conduct violates this policy. Responses should be proportionate and focused on keeping project spaces safe and productive.

## Reporting

Report conduct concerns privately through the contact route available on the maintainer's GitHub profile. Do not publish sensitive reports in public issues. Include relevant links and a factual description. Reports will be handled as discreetly as reasonably possible.

## Scope

This policy applies to repository issues, pull requests, code reviews, and other spaces operated for this project.
